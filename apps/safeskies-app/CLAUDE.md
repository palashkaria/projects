# SafeSkies App

Flight search tool that helps users find flights avoiding conflict zones and high-risk stopovers. Generates Kiwi.com search links with stopover country exclusions pre-applied.

## Stack

- **Framework**: TanStack Start (React) with Vite
- **Styling**: Tailwind CSS v4 (via `@tailwindcss/vite` plugin, CSS-native config in `src/styles.css`)
- **Deployment**: Cloudflare Workers (wrangler, domain: safeskies.supermoonhq.com)
- **TypeScript**: Strict mode, `#/*` and `@/*` path aliases to `./src/*`

## Commands

- `npm run dev` — dev server on port 3000
- `npm run build` — production build
- `npm run preview` — preview production build
- `npm run test` — run tests (vitest)

## Architecture

Single-page app. Landing page IS the search interface (no separate routes). Layout is viewport-locked with independently scrollable left (search form) and right (results) columns.

### Key directories

- `src/routes/` — TanStack file-based routes (`__root.tsx`, `index.tsx`)
- `src/components/` — React components (SearchForm, AirportAutocomplete, Toggle, etc.)
- `src/data/` — Static data (airports list, regions, conflict zone codes)
- `src/lib/` — Pure utility functions (Kiwi URL builder, airport search, date helpers)
- `src/hooks/` — `useSearchState` manages all search state + derives Kiwi URLs via useMemo

### Data flow

State lives in `useSearchState` hook → changes trigger `useMemo` → Kiwi URLs regenerate reactively → no "Generate" button needed.

### Kiwi URL format

```
https://www.kiwi.com/en/search/results/{from-slug}/{to-slug}/{YYYY-MM-DD}/no-return/?stopNumber={n}~true&stopoverCountriesList={ISO-codes}
```

Country codes are ISO 3166-1 alpha-2, comma-separated. `PS` (Palestine) is intentionally excluded — Kiwi doesn't recognize it and it breaks the entire filter.

## Design

Warm editorial aesthetic: parchment background with grid pattern, DM Serif Display headlines, Outfit body font, red-brown accent (`#b33a24`). CSS custom properties defined in `src/styles.css` via Tailwind `@theme`. Key classes: `.card-surface`, `.input-warm`, `.kicker`.

## Important notes

- Airport slugs must match Kiwi's URL format (e.g. `bengaluru-india`, `london-united-kingdom`)
- The `middleEastCodes` list has 13 countries (no PS) — must stay in sync with what Kiwi supports
- `routeTree.gen.ts` is auto-generated by TanStack Router — don't edit manually
